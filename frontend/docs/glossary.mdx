# Technical Glossary

This glossary provides definitions for key technical terms used throughout the Physical AI and Humanoid Robotics course.

## A

### Action (ROS 2)
A ROS 2 communication method for long-running tasks that provide periodic feedback and a final result.

## C

### Capstone Project
A culminating project that integrates knowledge and skills acquired throughout the course, typically solving a complex problem.

### Cognitive Planning
The process by which an AI (often an LLM) translates high-level natural language goals into a sequence of executable low-level actions for a robot.

### colcon
A command-line tool used to build, test, and install multiple software packages, commonly used in ROS 2 development.

## D

### Digital Twin
A virtual model designed to accurately reflect a physical object. In robotics, it refers to a high-fidelity simulation environment (like Gazebo or Isaac Sim) that mirrors a real robot and its surroundings.

### Docusaurus
A static site generator used to build documentation websites, serving as the platform for this course.

## G

### Gazebo
A powerful 3D robot simulator that provides robust physics, high-quality graphics, and convenient programmatic interfaces for simulating robots in complex environments.

### GPT-4
A large language model developed by OpenAI, used in this course for cognitive planning to translate natural language commands into robot actions.

## I

### IMU (Inertial Measurement Unit)
An electronic device that measures and reports a body's specific force, angular rate, and sometimes the orientation of the body, using a combination of accelerometers, gyroscopes, and sometimes magnetometers.

### Isaac ROS
A collection of hardware-accelerated ROS 2 packages that make it easier to develop high-performance robotics applications, leveraging NVIDIA GPUs and the Jetson platform.

### Isaac Sim
NVIDIA's photorealistic and physics-accurate virtual environment for developing, testing, and training AI-based robots, built on NVIDIA Omniverse.

### JWT-based Authentication (JSON Web Token)
A compact, URL-safe means of representing claims to be transferred between two parties. Used for securely transmitting information between client and server as a JSON object, enabling user authentication.

## L

### LiDAR (Light Detection and Ranging)
A remote sensing method that uses pulsed laser light to measure distances to the Earth. In robotics, it's used for mapping, localization, and obstacle detection.

### Link (URDF)
A rigid body element in a URDF file that represents a physical segment of a robot.

### LLM (Large Language Model)
A type of artificial intelligence program that can generate and understand human language, used here for cognitive planning.

## N

### Nav2
The ROS 2 navigation stack, providing a framework for mobile robots to autonomously navigate.

### Neon Postgres
A serverless PostgreSQL database with a generous free tier, used for backend data storage in this project.

### Node (ROS 2)
An executable process in ROS 2 that performs computation, typically responsible for a single module-scope purpose.

## P

### Physical AI
AI systems that function in the real world, comprehend physical laws, and interact with physical environments, often through embodied agents like robots.

### PyTorch
An open-source machine learning framework, used in this course for AI/ML development.

## Q

### Qdrant
A vector database and vector similarity search engine, used for storing and retrieving embeddings for the RAG chatbot.

## R

### RAG Chatbot (Retrieval-Augmented Generation)
A chatbot that retrieves relevant information from a knowledge base (e.g., course materials via Qdrant) and uses an LLM (e.g., GPT-4) to generate informed responses.

### ROS 2 (Robot Operating System 2)
A flexible framework for writing robot software, providing middleware, tools, and libraries for complex robot behaviors.

## S

### SDF (Simulation Description Format)
An XML format used to describe objects and environments in Gazebo, more powerful than URDF for Gazebo-specific features.

### Sim-to-Real Transfer
The process of transferring models or policies learned in a simulation environment to a real-world robot.

### Subscriber (ROS 2)
A node in ROS 2 that receives messages from a specific topic.

### Synthetic Data Generation (SDG)
The process of generating artificial datasets that mimic the statistical properties of real data, often used in simulation (e.g., Isaac Sim) to train AI models.

## T

### Topics (ROS 2)
Named buses over which ROS 2 nodes exchange messages asynchronously using a publish/subscribe communication model.

## U

### URDF (Unified Robot Description Format)
An XML format in ROS 2 for describing all kinematic and dynamic elements of a robot.

## V

### VLA (Vision-Language-Action)
A pipeline that translates natural language instructions into robot actions, integrating visual perception and language understanding.

### VSLAM (Visual Simultaneous Localization and Mapping)
The process of simultaneously estimating a robot's pose and building a map of its environment using visual input.

### Whisper (OpenAI)
An open-source general-purpose speech-to-text model developed by OpenAI, used to transcribe voice commands.
