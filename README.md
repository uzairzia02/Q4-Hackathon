# Physical AI and Humanoid Robotics Course

This repository contains the source code and content for the comprehensive course on Physical AI and Humanoid Robotics.

## Project Overview

This project is a 13-week capstone course designed to guide students from foundational AI concepts to controlling simulated and real-world humanoid robots. The primary goal is to bridge the gap between digital AI and physical embodiment.

## Getting Started

Please refer to the documentation in the `frontend/docs` directory for detailed instructions on setting up the development environment and getting started with the course material.
